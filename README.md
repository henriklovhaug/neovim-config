## Install Guide

```bash
git clone https://github.com/henriklovhaug/neovim-config.git ~/.config/nvim
```

### Prerequisites

- `ripgrep`
- `python3`
- `npm`
- `rust`
- `cmake`
- A nerd font. You can find them [here](https://www.nerdfonts.com)
